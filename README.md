# Agricultural Shredder Design and Assembly using SolidWorks

## Project Overview

This project involves the design, modeling, and assembly of an Agricultural Shredder using SolidWorks CAD software. The machine is intended for shredding agricultural residues such as crop stalks, leaves, grass, and other organic waste into smaller pieces for easier disposal, composting, or recycling.

The project demonstrates the application of mechanical design principles, CAD modeling techniques, and assembly design practices in developing a complete shredding machine.

---

## Objectives

* Design a functional agricultural shredder in SolidWorks.
* Model all machine components individually.
* Create a fully constrained assembly.
* Develop an efficient power transmission mechanism.
* Understand machine design and manufacturing considerations.
* Visualize the working of a shredding system before physical fabrication.

## Major Components

### 1. Hopper

The hopper guides agricultural waste into the shredding chamber while ensuring safe feeding of material.

### 2. Shredding Blades

The blades are mounted on rotating shafts and perform the cutting action on incoming material.

### 3. Shafts

The shafts transmit rotational motion from the drive system to the cutting blades.

### 4. Spur Gears

The gear pair synchronizes the rotation of the shredding shafts and provides torque transmission.

### 5. Bearings

Bearings support the rotating shafts and reduce friction during operation.

### 6. Electric Motor

The motor acts as the primary power source for the shredder.

### 7. Frame

The frame provides structural support and stability to the entire assembly.

### 8. Housing

The housing encloses the shredding mechanism and improves operational safety.

---

## Working Principle

1. Agricultural waste is fed through the hopper.
2. The electric motor drives the primary shaft.
3. The spur gear arrangement transfers motion to the secondary shaft.
4. The rotating blades cut and shred the incoming material.
5. The shredded output is discharged through the outlet section.

## CAD Modeling Process

* Individual parts were created using SolidWorks Part Design.
* Appropriate dimensions and constraints were applied.
* Components were assembled using mates and assembly constraints.
* Interference checks were performed to ensure proper fitment.
* Motion compatibility was verified through assembly visualization.
